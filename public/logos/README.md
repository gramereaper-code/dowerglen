# Client Logos Directory

This directory is for official client logo assets.

## Current Status
The website currently uses text marks for the following clients:
- RocoMamas
- Mugg & Bean
- SPAR
- Chicken Licken

## Adding Official Logos
To replace the text marks with official logos:

1. Add logo files to this directory (preferably PNG or SVG format with transparent backgrounds)
2. Recommended naming convention:
   - `rocomamas.png` or `rocomamas.svg`
   - `mugg-bean.png` or `mugg-bean.svg`
   - `spar.png` or `spar.svg`
   - `chicken-licken.png` or `chicken-licken.svg`

3. Update the client marks in `lib/site.ts` to reference the logo files instead of text

## Logo Specifications
- Format: PNG or SVG preferred
- Background: Transparent
- Size: 200-400px width recommended
- Color: White or light versions work best on dark backgrounds
